# Wiki deslop (2026-09-24)

Henry chose to remove archive history and low-value views to keep Wiki focused on notes and live agents. Future run completion keeps only a compact receipt and saved artifacts. Existing files in `~/me/fun/agent-archive` were not deleted.

| Cut | Merged PR |
|---|---|
| Note graph | [#304](https://github.com/hwang2409/wiki/pull/304) |
| Cost dashboard and five-second collector | [#305](https://github.com/hwang2409/wiki/pull/305) |
| Automatic archive parity, startup reconciliation, and unknown-kind scans | [#306](https://github.com/hwang2409/wiki/pull/306) |
| Run replay scrubber | [#307](https://github.com/hwang2409/wiki/pull/307) |
| Full run archive writes; replaced by receipts and artifact files | [#308](https://github.com/hwang2409/wiki/pull/308) |
| Archive history on agent page and `/api/agents` polling | [#309](https://github.com/hwang2409/wiki/pull/309) |
| Archived workers in fleet graph | [#310](https://github.com/hwang2409/wiki/pull/310) |
| Archive-wide palette scans; recent 40 receipt catalog limit | [#311](https://github.com/hwang2409/wiki/pull/311) |
| Archived transcript fallback; saved-artifact-only links | [#312](https://github.com/hwang2409/wiki/pull/312) |

Why: Henry rarely opens archived runs. Full archive reads caused high CPU during agent polling, palette search, and startup. Saved artifacts still open from the palette. The ticket dashboard can read completion receipts on an explicit request.

The changes are merged in `origin/main`. Henry will rebuild Wiki.app; no native build or relaunch followed these PRs. The installed app may still run older code until then. See [[agents-list-cpu-rca-2026-09-24]] and [[palette-cpu-rca-2026-09-24]] for prior measurements.
