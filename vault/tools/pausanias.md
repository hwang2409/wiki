# Pausanias

Public repository: https://github.com/hwang2409/pausanias. Created 2026-09-16 with README.md and DESIGN.md on main. Local directory tracks origin/main.

Proposed design: `/Users/henry/me/fun/pausanias/DESIGN.md` (2026-09-16). No implementation exists.

- Henry requested a design after discussing Mem0 and automatic context injection.
- Proposal: retrieve bounded markdown excerpts before inference; retain explicit search and source reads.
- First version: local SQLite FTS, source/version checks, project scopes, one Claude Code hook adapter.
- Compare no memory, model-chosen retrieval, automatic retrieval, and both together before default adoption.
- Embeddings and conversation extraction remain deferred. These are design proposals, not approved implementation choices.
- Source: the design document and Henry’s request in the 2026-09-16 session.
